# Security Policy

## Context

Reports that flag intended functionality without demonstrating an actual unintended impact will be closed.

A valid finding is one where an attacker can compromise **the operator** or **the operator's machine** through Koi in a way the operator did not authorize or intend or know.

## Supported Versions

Only the latest release on `main` is actively maintained.

## Reporting a Vulnerability

Please do not use the advisory on github and send reports to **koi-handler@proton.me** with:

- A clear description of the impact
- Steps to reproduce


You should receive an acknowledgment within a reasonable timeframe.
